安装

macOS 你的系统

macOS 13 及以上，Intel 和 Apple 芯片都支持
  1. 推荐：打开「终端」，粘贴这行命令回车，会装到「应用程序」并打开： 
    curl -L -o /tmp/KeyCat-macOS.zip https://github.com/ElloboDK/KeyCat/releases/latest/download/KeyCat-macOS.zip && unzip -qo /tmp/KeyCat-macOS.zip -d /Applications && open /Applications/KeyCat.app
  2. 首次启动在「系统设置 → 隐私与安全性 → 输入监控」里允许 KeyCat，再重新打开它。
  3. 用浏览器下载的话，解压后拖进「应用程序」；提示「已损坏」时在终端执行 xattr -dr com.apple.quarantine /Applications/KeyCat.app。
下载 KeyCat-macOS.zip

Windows 你的系统

Windows 10 / 11，安装包只有几 MB
  1. 下载 KeyCat-Windows-Setup.exe 并运行。
  2. SmartScreen 拦截时点「更多信息 → 仍要运行」。
  3. 猫住在托盘里，右键猫或托盘图标打开菜单。玩游戏时猫没反应，就在菜单里打开「以管理员身份运行」。
下载 KeyCat-Windows-Setup.exe

两个平台都会自动更新，装一次就好。历史版本见 Releases。
